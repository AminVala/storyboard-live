# StoryBoard Live 0.6.7 — M6.7 Implementation

Implemented from the locked M6.7 specification.

## Changes
- Manifest schema 9.
- Dedicated 720x1280 mobile portrait frame set; desktop frames are no longer blindly cropped for the portrait demo.
- Real theme-header discovery expanded while still refusing to generate a duplicate header.
- Header reveal starts at 90% sequence progress and is fully visible at completion.
- WordPress admin-bar offset is measured from the real `#wpadminbar` height instead of relying only on fixed 32/46 px values.
- Mobile live-content panel is constrained to the same viewport composition to remove the large dead gap seen in M6.6 screenshots.
- Demo remains generic and contains no site-specific branding.
- No external fonts, telemetry, remote API, or scroll hijacking were added.

## Known external Lighthouse items
- Mixed-content URLs generated by Elementor upload CSS are external to StoryBoard Live.
- Google Fonts requested by Elementor/theme stack are external to StoryBoard Live.
- Server-response outliers are not modified by the runtime.

## Release gate
M7 remains blocked until M6.7 passes the locked functional, header, responsive, accessibility, and Lighthouse gates on staging.
