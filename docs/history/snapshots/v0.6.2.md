## M6.2 delta from M6.1

M6.2 changes the runtime manifest from schema 5 to schema 6 and introduces independent responsive variants: desktop, tablet, mobile portrait, and mobile landscape. Variant selection is based on viewport dimensions/orientation, with debounced runtime switching and normalized progress preservation. Overlay and site-header timelines use normalized progress instead of frame numbers.
