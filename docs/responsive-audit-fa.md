# بازبینی مسیر فعال StoryBoard Live

مبنای بازبینی: commit `1b4a10bfbf98fdc6f6eb5029ce8b9d5c535b0543` و نقشهٔ ذهنی شهر هنر، با اولویت درخواست جدید برای پخش روی موبایل. این نسخه RC است؛ نتیجهٔ آزمون نصب واقعی WordPress/Elementor، خرید WooCommerce یا دستگاه واقعی محسوب نمی‌شود.

## اصلاحات این شاخه

| ایراد | اصلاح |
|---|---|
| ویزارد JSON ذخیره می‌کرد ولی FrameManager فقط آرایه می‌خواند | خواندن سازگار هر دو قالب؛ ذخیرهٔ جدید به قالب آرایه |
| تمام فریم‌ها هم‌زمان بارگیری می‌شدند | بارگیری نزدیک محدودهٔ دید؛ دو درخواست هم‌زمان و هشت تصویر در cache |
| خرابی فریم اول، کل پیش‌بارگیری را متوقف می‌کرد | خطای مستقل هر تصویر، timeout و حفظ پوستر/آخرین تصویر؛ تلاش مجدد با online |
| بارگیری بعد از توقف اسکرول، تصویر را به‌روز نمی‌کرد | رسم دوباره پس از رسیدن تصویر و محاسبهٔ آخرین موقعیت در rAF |
| محاسبه با offsetTop در والد نسبی Elementor اشتباه بود | محاسبه با مستطیل واقعی wrapper و ارتفاع واقعی stage |
| نمایش فقط بر اساس عرض بود | همان فریم‌ها با چینش عمودی یا افقی و واکنش به resize؛ بدون برش تصویر روی موبایل و تبلت |
| ارتفاع نوار مدیریت همیشه ۳۲px فرض شده بود | سنجش هندسهٔ نوارها و هدرهای ثابت/چسبان؛ بدون دوباره‌شماری |
| stage دارای aria-hidden بود و لینک‌های نامرئی قابل Tab بودند | stage قابل دسترسی؛ hidden/inert برای کارت غیرفعال؛ حفظ کارت دارای فوکوس |
| نبود JS یا کاهش حرکت باعث فضای خالی/محتوای پنهان می‌شد | پوستر و تمام متن‌ها و لینک‌ها در خروجی سرور؛ فعال‌سازی تدریجی انیمیشن |
| پیش‌نمایش فقط در is_admin ثبت می‌شد | ثبت hook پیش‌نمایش و نوار ابزار در frontend؛ ثبت asset قبل از enqueue؛ پاسخ ۴۰۳ و عدم cache پیش‌نمایش |
| شورت‌کد، وضعیت انتشار را بررسی نمی‌کرد | جلوگیری از نمایش عمومی پیش‌نویس، خصوصی و محتوای رمزدار؛ پیش‌نمایش برای ویرایشگر مجاز |
| JSON در script و مقدار height محدود نبود | JSON_HEX_* و اعتبارسنجی طول CSS |
| لوگوی ذخیره‌شدهٔ مراحل نمایش داده نمی‌شد | استفاده از دادهٔ نرمال‌شدهٔ manifest و مرتب‌سازی مراحل |
| nonce با مجوز ویرایش همان سکانس اشتباه گرفته شده بود | کنترل نوع پست و edit_post در endpointهای ویزارد/وضعیت؛ مجوز مستقل انتشار در REST |
| PHP اعلام‌شده با syntax واقعی ناسازگار بود | یکسان‌سازی حداقل PHP به ۸٫۲ در header، readme و Composer |
| متن Canvas Editor به پخش‌کننده نمی‌رسید | در نبود Content Steps، متن ذخیره‌شده به کارت معنایی تبدیل می‌شود؛ URL دکمه در ویرایشگر اصلی قابل ذخیره است |
| درخواست خواندن overlay می‌توانست استخراج دوباره انجام دهد | اولویت خواندن دادهٔ ذخیره‌شده؛ عدم اجرای استخراج برای آن خواندن |

## قرارداد نمایش

- عمودی: تصویر کامل بالای کارت متن. همان ترتیب فریم‌های دسکتاپ استفاده می‌شود.
- افقی تا عرض ۱۳۶۶px: تصویر کامل و کارت متن کنار هم. دستگاه افقی به خاطر ارتفاع کم به پوستر ثابت تبدیل نمی‌شود.
- دسکتاپ عریض: تصویر با cover و کارت متن روی آن.
- چرخش دستگاه: محاسبهٔ دوبارهٔ اندازه و موقعیت؛ بدون scrollTo اجباری در پخش‌کننده.
- Reduced Motion، Save-Data، تنظیم صریح Disable on Mobile و نبود JS: نمایش ثابت با لینک‌ها و متن قابل استفاده.
- height صریح شورت‌کد اولویت دارد؛ بدون آن طول حرکت بر حسب تعداد فریم و scrollSpeed محاسبه می‌شود. برای روایت طولانی `[storyboard_live id="123" height="420vh"]` کاربرد دارد.
- موقعیت و رنگ آزاد متن در Canvas Editor به چیدمان دقیق خروجی منتقل نمی‌شود؛ پل سازگاری، متن و اولین CTA معتبر را در کارت خوانا ارائه می‌کند. Content Steps مسیر مناسب برای روایت چندمرحله‌ای است. هندسهٔ آزاد و داده‌های ویرایشگر حذف نشده‌اند.

| نیاز | وضعیت واقعی |
|---|---|
| ۱۰۰ فریم سینمایی پیوسته | تولید و QC هنری انجام نشده؛ تغییر پخش‌کننده جایگزین تولید دارایی نیست |
| سقف ۱۰۰ فریم در پنل | سقف فعلی طرح‌ها ۲۴/۳۶ است؛ این شاخه محدودیت طرح‌ها را افزایش نمی‌دهد. قالب‌های ۷۲/۱۲۰ فریمی با آن‌ها هم‌خوان نیستند |
| Golden Master و سه نسخهٔ دستگاه | کلاس‌های قدیمی runtime و single-image در Plugin::boot فعال نیستند؛ این RC از مسیر فعال frame-sequence استفاده می‌کند و سناریوی مستقل عمودی تولید نمی‌کند |
| hotspot و قیمت/موجودی WooCommerce | در مسیر فعال StoryBoard Live پیاده‌سازی نشده؛ با کارت CTA عمومی یکی نیست. Hero Engine مستقل چنین قرارداد دیگری دارد |
| اثر سینمایی واقعی از یک تصویر | مسیر GD، zoom روی تصویر می‌سازد؛ این کار تولید منطقی مراحل نقاشی نیست |
| REST Wizard جدید | کنترل دسترسی اصلاح شده، اما boot فعلی این مسیر را متصل نمی‌کند؛ schema محتوای آن با Content Steps متفاوت است و برای مهاجرت کامل نیاز به کار جداگانه دارد |
| سلامت تمام مسیرهای AI | سرویس پولی فراخوانی نشده؛ pipeline و خروجی هنری تأیید نشده‌اند |
| کیفیت انتشار | تست نصب، Elementor، Safari/Firefox، گوشی واقعی، شبکه ضعیف، خرید و CWV همچنان gate انتشارند |

## بازتولید آزمون‌ها

```sh
php tests/php-runtime.php
php tests/php-runtime.php --fixture > tests/fixture.html
npm ci
npx playwright install chromium
npm test
```

PHP contract tests از بدل‌های WordPress استفاده می‌کنند. آزمون مرورگر از HTML تولیدشده توسط همین شورت‌کد و تصاویر عدددار آزمایشی استفاده می‌کند؛ نه از سایت واقعی. گزارش و screenshotها در `test-results/` نوشته می‌شوند و workflow آن‌ها را نگه می‌دارد. پیش از جایگزینی نسخهٔ نصب‌شده از فایل‌ها و پایگاه داده پشتیبان بگیرید؛ بازگشت این شاخه به نسخهٔ قبل نیاز به مهاجرت داده ندارد.
