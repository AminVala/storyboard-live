## Important static observations

### 1. Manifest schema 9

`RuntimeManifest` declares schema version 9 and provides explicit desktop/mobile frame sets. Desktop uses 30 `1280x720` frames; mobile portrait uses 30 dedicated `720x1280` frames. Mobile portrait is therefore no longer dependent on blind desktop cropping.

### 2. Header contract

The runtime searches a fixed internal whitelist of known header patterns, including StoryBoard-specific data attributes and common Elementor/theme header markers. It does not create a replacement header. Static code review found no arbitrary selector field exposed through the Ready Templates editor.

### 3. Ready Templates boundary

The new M6.7.1 feature is deliberately narrow. It creates an editable Sequence draft from an immutable built-in structure. It does not introduce a visual drag-and-drop timeline, arbitrary JavaScript/CSS/selectors, remote marketplace or telemetry.

### 4. Security boundary

Template selection is protected by capability checks and a per-template nonce. The structure editor verifies a save nonce, ignores autosaves/revisions, checks `edit_post`, bounds numeric values and sanitizes text/key fields. Handoff/header mode values are constrained by code rather than accepted from arbitrary POST values.

### 5. Production-readiness limitation

`vendor/autoload.php` in the artifact is a development PSR-4 loader rather than an optimized Composer production autoloader. `composer.json` requests `optimize-autoloader: true`, but this artifact does not prove that an optimized production dump was generated. This is a **release-hardening observation**, not a reason to falsify the historical snapshot.
