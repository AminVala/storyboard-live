# M6.7.1 Ready Templates extension

This build stays inside M6.7. M7 is not started.

## Added
- Ready Templates submenu under StoryBoard Live.
- Immutable built-in `Creative Studio Production Sheet` template.
- Structural contract derived from the supplied production-sheet reference:
  - 120 desktop frames
  - 12 beats
  - 4 scenes
  - master reference frame 70
  - golden frame 120
  - five reference keyframes A/B/C/D/E
  - HTML-only overlay timeline
  - real theme-header reveal near the final stage
  - reversible golden handoff
  - independent desktop/mobile output policy
- Secure `admin-post` template selection with capability and nonce checks.
- Selecting a template creates a normal independent Sequence draft.
- Editable Story Structure meta box for scenes, beats, keyframes, overlays, responsive outputs, header timing and handoff timing.
- Built-in templates are not mutated when a created Sequence is edited.
- Brand-neutral admin preview; no site-specific brand/logo/copy is bundled.

## Deliberately not added
- No visual drag-and-drop timeline editor.
- No arbitrary JavaScript/CSS/selectors.
- No remote template marketplace.
- No telemetry or remote API.
- No M7 work.
